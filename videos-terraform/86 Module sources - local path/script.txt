A local module is the fastest way to share code inside one repository.

A local module source points to a directory in the same repository, usually with a relative path such as ./modules/network. It is ideal while developing a pattern alongside its callers. Terraform reads the module code from that path during initialization and plans.

Keep local module directories self-contained with variables, outputs, versions, and a clear README. Use paths relative to the calling module, not assumptions about the developer machine. Test changes through representative root modules because a local edit can affect every caller in the repository.

Using broad relative paths such as ../../shared makes repository moves risky and can confuse readers. Local modules also cannot be versioned independently from the repository commit. When consumers need independent release cadence, consider a registry or Git source instead.
