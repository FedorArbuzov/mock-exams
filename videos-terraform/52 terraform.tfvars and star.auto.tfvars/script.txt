Some variable files load automatically. That is powerful and risky.

Terraform automatically loads terraform.tfvars, terraform.tfvars.json, and files ending in .auto.tfvars or .auto.tfvars.json. These files assign root-module variable values. They are useful for stable local or environment values that should accompany the configuration.

Keep a checked-in example file for required values and use ignored files for local secrets. Automatic loading is simple, but explicit environment files passed through deployment commands make provenance clearer. Choose one team convention and document precedence for operators.

A forgotten star.auto.tfvars file can silently alter a plan on one machine. Different automatic files also make it unclear which values won. Avoid placing production secrets in version control, even if a variable is marked sensitive.

Use predictable tfvars conventions and keep secrets out of Git.
