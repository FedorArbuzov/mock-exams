ECR stores the container images your workload actually runs.

Amazon ECR is a private container image registry. Terraform can create repositories, configure image scanning, encryption, lifecycle policies, permissions, and tags. Applications then deploy images referenced by repository URL and immutable digest or controlled tag.

Create lifecycle rules to remove unneeded images while retaining releases needed for rollback. Enable scanning according to your security process and grant pull access only to the workload identities that need it. Have CI authenticate, build, scan, and push images separately from infrastructure apply.

Using only a mutable latest tag makes it hard to prove which code is running or roll back safely. Aggressive lifecycle policies can delete needed artifacts. Repository creation does not grant every runtime role permission to pull images.

Deploy immutable image references and retain enough artifacts for rollback.
