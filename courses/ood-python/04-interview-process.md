# 04. Процесс: 45 минут OOD интервью

## Введение

Структура важнее количества классов. Интервьюер ждёт **диалог**, не монолог в коде.

---

## Таймлайн

| Мин | Действие |
|-----|----------|
| 0–5 | Повторить задачу, **уточнить** scope |
| 5–10 | Сущности, use cases (2–3) |
| 10–15 | API публичных классов / методов |
| 15–35 | Реализация happy path + 1 extension point |
| 35–40 | Тест или walkthrough |
| 40–45 | Trade-offs, что добавили бы |

## Вопросы к интервьюеру
