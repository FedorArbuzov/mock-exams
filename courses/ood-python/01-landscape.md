# 01. Ландшафт OOD-раунда

## Введение

**OOD** на собеседовании — не UML на 20 классов, а **ясная модель** под требования за 45 минут. В Python часто совмещают с **live coding** одной задачи (LRU, лимитер).

---

## Чем OOD отличается от system design

| | OOD | System design |
|--|-----|----------------|
| Масштаб | классы в процессе | сервисы, БД, очереди |
| Время | 45–60 мин | 45–60 мин другой фокус |
| Артефакт | API + 3–7 классов | диаграмма + trade-offs |

[microservices-patterns](../microservices-patterns/README.md) — не замена OOD.

---

## Что оценивают

- Уточнение требований
- Выделение сущностей
- Расширяемость (open/closed)
- Чистый API
- Тестируемость
- Коммуникация

---
