# 04. Компетенции: что ищут по уровням

## Введение

Компании называют компетенции по-разному (Amazon Leadership Principles, Google googliness, «наши ценности»). Суть одна: **повторяемые поведения**. Карта компетенция → история ускоряет подготовку.

---

## Универсальные компетенции (инженер)

| Компетенция | Что доказать |
|-------------|--------------|
| **Ownership** | end-to-end, не «не моя зона» |
| **Bias for action** | решение при неполных данных |
| **Dive deep** | root cause, не патч симптома |
| **Deliver results** | outcome в срок |
| **Earn trust** | честность, прозрачность |
| **Disagree and commit** | спор → решение → поддержка |
| **Learn and be curious** | рост, feedback |
| **Mentor / develop** | помог другим расти |

---

## Amazon LP (сжато)

Часто встречаются на международных и у клонов в РФ:

| LP | История из |
|----|------------|
| Customer Obsession | решение в пользу пользователя vs внутренний удобство |
| Ownership | дежурство, долг после релиза |
| Invent and Simplify | убрали сложность |
| Insist on Highest Standards | quality gate в CI |
| Bias for Action | MVP vs analysis paralysis |
| Learn and Be Curious | новый стек / сертификация с применением |
| Hire and Develop the Best | интервью, менторство |
| Frugality | cost-aware design ([finops](../finops/README.md)) |

Не нужно зубрить 16 — **6–8** релевантных историй покрывают большинство вопросов.

---

## Middle vs Senior

| | Middle | Senior |
|--|--------|--------|
| Scope | задача / фича | сервис / домен / команда |
| Влияние | команда 3–8 | кросс-команда |
| Неопределённость | уточняет у lead | формулирует проблему сам |
| Ошибки | признаёт, фиксит | меняет процесс, чтобы не повторилось |

## Подзадачи

**Время:** ~50 мин.

### 4.1 JD mapping (20 мин)

Возьмите реальную вакансию; выпишите 6 компетенций из текста → сопоставьте с story-bank (есть/нет).

### 4.2 Gap plan (15 мин)

3 компетенции без истории — откуда взять (работа, capstone, open source).

### 4.3 LP pick (15 мин)

Выберите 6 LP; одна строка «моя история ID» на каждый.
