# 11. Командная работа и менторство

## Введение

«Работали в команде» — тривиальный ответ. Нужны **конкретика**: code review, парное решение, онбординг, разделение работы, разрешение блокеров.

---

## Темы

| Вопрос | Угол |
|--------|------|
| Сложный коллега | empathy + границы ([06](06-conflict.md)) |
| Помогли джуну | менторство, измеримый рост |
| Кросс-функциональная команда | PM, QA, design |
| Code review | как даёте feedback |

---

## Feedback (SBI)

**Situation – Behavior – Impact** для review:

«В PR #42 (S) предложил переименовать без тестов (B) — риск регрессии в billing (I). Добавили contract test вместе.»

---

## Подзадачи

**Время:** ~55 мин.

### 11.1 Менторство (20 мин)

STAR: кого помогли; что изменилось за 1–3 мес.

### 11.2 Code review (20 мин)

История конструктивного жёсткого review (вы дали или получили).

### 11.3 Remote collaboration (15 мин)

Как синхронизировались (async doc, standup) — актуально для [18](18-remote-english.md).
