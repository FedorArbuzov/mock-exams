# 18. Удалёнка, async, английский

## Введение

Distributed teams — отдельные behavioral: коммуникация, timezone, документация. Международные компании — **английский** на том же STAR.

---

## Remote / async

| Компетенция | История |
|-------------|---------|
| Over-communication | статусы, RFC в Notion |
| Documentation | ADR вместо «созвонимся» |
| Timezone | handoff, overlap windows |
| Trust | deliver без микроменеджмента |

Связь: [devops-culture/10](../devops-culture/10-cicd-culture.md) — async culture.

---

## English behavioral

| Совет | Деталь |
|-------|--------|
| Простые фразы | лучше, чем сложные с ошибками |
| STAR те же | структура на англ проще, чем «красивый» текст |
| Пауза | «Let me think for a moment» — нормально |
| Техтермины | API, deployment, on-call — не переводить |

Подготовьте **2 истории** полностью на английском (письменно + вслух).
