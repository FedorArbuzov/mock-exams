# Behavioral Interviews

Теоретический курс **поведенческих (soft skills) собеседований** для инженеров: **STAR**, банк историй, конфликты, провалы, лидерство, мотивация, reverse questions и mock-сценарии. Формат «книги» на русском с **подзадачами**; **без стенда** — практика в документе `story-bank.md`.

**Для кого:** backend, DevOps, platform, SRE — перед **middle+** интервью (продукт, банк, Big Tech, сильный стартап), где после алго и design идёт **1–3 раунда** «про опыт».

**Предварительно:**

| Навык | Зачем |
|-------|--------|
| 1+ год коммерческого опыта **или** сильные pet/capstone | материал для историй |
| Пройденный capstone | [fastapi/42](../fastapi/42-capstone.md), [gitlab-advanced/15](../gitlab-advanced/15-final-project.md) |

**Полезно параллельно:** [python-algorithms](../python-algorithms/README.md), [microservices-patterns](../microservices-patterns/README.md), [devops-culture](../devops-culture/README.md), [sre/09](../sre/09-postmortems.md).

## Как читать

- Главы **01–17** — ~**40–55 мин** (теория + **подзадачи**).
- Главы **18–20** — mock и **финальный story portfolio** (**3–4 ч**).
- Ведите **`story-bank.md`** с первой главы — не откладывайте на конец.
- Истории **без NDA**: метрики округлите, имена замените.

**Время:** ~**12–16 часов**.

## Что должно получиться

- **8–12** отрепетированных историй в STAR на разные компетенции.
- Ответ «о себе» на **2 и 5 минут** без воды.
- Честный рассказ о **провале** с learning (не victim story).
- **10+** вопросов работодателю без «нет вопросов».
- Файл **Story Portfolio** для быстрого повторения перед раундом.
