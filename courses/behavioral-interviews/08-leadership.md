# 08. Лидерство и влияние без должности

## Введение

«Лидерство» на интервью ≠ «был тимлидом». Это **сдвинули систему** без формальной власти: RFC, стандарт, кросс-командная инициатива.

---

## Примеры для инженера

| Ситуация | Leadership signal |
|----------|-------------------|
| Внедрили contract tests в 3 репо | стандарт качества |
| Организовали guild по observability | community |
| Убедили security в pragmatic rollout | influence |
| Вели релиз как release captain | ownership |

Senior: **другие повторяют** ваш паттерн без вашего участия.
