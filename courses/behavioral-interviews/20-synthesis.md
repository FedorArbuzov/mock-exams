# 20. Синтез: Story Portfolio

## Финальное задание

Соберите **Story Portfolio** — один документ для повторения за 24 часа до интервью. Время: **2–3 часа**.

---

## Deliverable: Story Portfolio

### 1. Meta

| Поле | Значение |
|------|----------|
| Целевая роль | backend / DevOps / SRE |
| Уровень | middle / senior |
| Компания (тип) | |
| Дата интервью | |

### 2. Pitches

- **30 сек** tell me about yourself  
- **2 мин** версия  
- **Why us** (5 предложений)  
- **Why leaving** (3 предложения)

### 3. Story index

| ID | Title | Компетенции | 60-sec hook |
|----|-------|-------------|-------------|
| … | … | … | одна строка |

Минимум **8** полных STAR в приложении.

### 4. Question map

| Типичный вопрос | ID | Backup ID |
|-----------------|-----|-----------|
| Conflict | | |
| Failure | | |
| … | | |

### 5. Reverse questions

Top **10** с отметкой «уже спросил на раунде 1».

### 6. Consistency sheet

Метрики и даты по историям (не противоречить себе).

### 7. English (если нужно)

2 истории — bullet STAR на английском.

### 8. Mock scores

Из [19](19-mock-scenarios.md): сценарий | средний балл | top fix.

### 9. Red lines

Темы NDA / не обсуждать.

### 10. Day-before checklist

- [ ] Прочитать portfolio 1 раз  
- [ ] 2 истории вслух  
- [ ] 5 reverse questions  
- [ ] Сон / логистика  

---
