# 07. vim: essentials

## Зачем учить vim, если есть IDE

На сервере по SSH часто **нет** графики. Конфиг nginx, unit systemd, правка `sshd_config` — через терминал. **vim** (или совместимый **vi**) есть почти в любом минимальном образе Docker и в rescue-режиме. Вам не нужен мастерский уровень — нужно **уверенно открыть файл, исправить строку, сохранить и выйти**, не оставив swap-файл и не сломав синтаксис.

Если совсем не заходит — для лаб можно `nano`, но в проде и на собеседованиях ждут vim.

## Режимы — главная идея

vim — не «блокнот». В **Normal** вы двигаете курсор и отдаёте команды; в **Insert** печатаете текст; в **Command-line** (`:`) сохраняете и выходите.

| Режим | Как попасть | Что делать |
|-------|-------------|------------|
| Normal | Esc (по умолчанию при открытии) | `dd`, `yy`, `/поиск` |
| Insert | `i`, `a`, `o` | набор текста |
| Command | `:` в Normal | `:w`, `:q`, `:wq` |

Новички застревают, потому что печатают в Normal — буквы исчезают как команды. Нажмите **Esc** и начните снова.

## Минимальный набор на каждый день

```bash
vim /tmp/lab.txt
```

| Действие | Клавиши |
|----------|---------|
| Вставка перед курсором | `i` |
| Вставка после курсором | `a` |
| Новая строка ниже | `o` |
| Выйти в Normal | `Esc` |
| Сохранить и выйти | `:wq` + Enter |
| Выйти без сохранения | `:q!` |
| Сохранить, остаться | `:w` |
| Удалить строку | `dd` |
| Отменить | `u` |
| Повторить | `Ctrl+r` |
| Поиск вперёд | `/текст` Enter, затем `n` |

## Навигация без мыши

- `h j k l` — влево, вниз, вверх, вправо
- `0` — начало строки, `$` — конец
- `gg` — начало файла, `G` — конец
- `:10` + Enter — перейти на строку 10

Полезно при ошибке «строка 42 в nginx.conf»: `vim +42 /etc/nginx/nginx.conf`.

## Массовые правки

```text
:%s/old/new/g      заменить все old на new (подтверждение: .../gc)
3dd                удалить 3 строки
yy p               скопировать строку и вставить ниже
```

Осторожно с `:%s` на проде — сначала бэкап или `:w` копия.

## ~/.vimrc (по желанию)

```vim
set number
set tabstop=2
set expandtab
syntax on
```

Создайте `~/.vimrc` на lab — настройки сохранятся в контейнере до `compose down -v`.
