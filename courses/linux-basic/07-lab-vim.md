# 07. Лаба: vim

15–20 минут — достаточно, чтобы перестать бояться `:q!`. Делайте медленно: после каждого шага нажимайте **Esc** и смотрите, в каком режиме вы (внизу не должно быть `-- INSERT --`, если вы в Normal).

## Стенд

`docker compose exec lab bash`

---

## Задание 1. Создать файл с нуля

```bash
vim /tmp/vim-lab.txt
```

1. Нажмите `i` — внизу `-- INSERT --`
2. Наберите две строки: `hello lab` и `line two`
3. `Esc`
4. `:wq` + Enter

Проверка:

```bash
cat /tmp/vim-lab.txt
```

---

## Задание 2. Правка и отмена

```bash
vim /tmp/vim-lab.txt
```

1. Стрелками на вторую строку
2. `dd` — строка исчезла
3. `u` — вернулась
4. `o` — новая строка ниже, в Insert; напишите `line three`
5. `Esc` → `:w`

Выйдите `:q` и проверьте `cat`.

---

## Задание 3. Поиск и замена

```bash
vim /tmp/vim-lab.txt
```

1. `/lab` + Enter — курсор на `lab`
2. `n` — следующее вхождение (если есть)
3. `:%s/lab/LAB/g` + Enter
4. `:wq`

```bash
grep LAB /tmp/vim-lab.txt
```

---

## Задание 4. Выйти без сохранения

```bash
vim /tmp/vim-lab.txt
```

Измените что-нибудь, затем `:q!` — файл на диске **без** последней правки (проверьте `cat`).

---

## Задание 5. Открыть на нужной строке

```bash
vim +2 /tmp/vim-lab.txt
```

Курсор должен оказаться на строке 2.

---

## Критерии успеха

- [ ] Файл создан и сохранён через `:wq`
- [ ] `dd` и `u` отработали
- [ ] Замена `:%s/...` применена
- [ ] `:q!` не испортил файл на диске
