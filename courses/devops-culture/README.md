# DevOps Culture

Теоретический курс об **организации и культуре** DevOps: **DORA metrics**, **Team Topologies**, **закон Конвея**, взаимодействие команд, платформенное мышление и связь с **CI/CD**. Формат «книги» на русском, без обязательных лаб.

**Для кого:** тимлиды, platform / DevOps / SRE, архитекторы; инженеры, которые хотят понимать **почему** «у нас DevOps в названии, а релизы раз в квартал».

## Что должно получиться

- Объясняете **четыре DORA-метрики** и не путаете их с «количеством деплоев в Jira».
- Нарисуете **топологию команд** (stream / platform / enabling) для продукта.
- Примените **закон Конвея** к спору «монолит vs микросервисы».
- Свяжете **`.gitlab-ci.yml`** с культурой частых малых изменений.
- Оформите **one-pager** «как мы организованы и что улучшаем в квартал».

## Требования

Только чтение. Для финала полезен опыт (или вымышленный кейс) команды 20–80 человек.
