# 01. Типы, переменные, константы

## Объявление переменных

```go
var count int = 0          // полная форма
var name string            // zero value: ""
total := 42                // короткая форма, только внутри функций
```

**Zero value** — значение по умолчанию: `0`, `""`, `false`, `nil` для указателей, slices, maps, channels.

Правило: **`:=` там, где тип очевиден**; `var` — на уровне пакета или когда нужен явный тип.

## Базовые типы

| Тип | Примеры | Zero value |
|-----|---------|------------|
| `int`, `int64` | счётчики, индексы | `0` |
| `float64` | цены, метрики | `0` |
| `string` | текст, JSON-поля | `""` |
| `bool` | флаги | `false` |
| `byte` (`uint8`) | сырые байты | `0` |
| `rune` (`int32`) | Unicode-символ | `0` |

Go **не приводит типы неявно** (в отличие от JavaScript):

```go
var a int = 5
var b float64 = float64(a) // явное преобразование
```

## Константы и iota

```go
const MaxRetries = 3

const (
    StatusTodo = iota // 0
    StatusDone        // 1
)
```

`iota` удобен для enum-подобных констант в одном `const` блоке.

## Именование

- **Экспорт:** имя с **заглавной** буквы (`User`, `ParseConfig`) — видно другим пакетам.
- Стиль: `MixedCaps`, без `snake_case`.
- Аббревиатуры: `HTTPClient`, `userID`.

## Сравнение с JS/Python (коротко)

| | Go | JS | Python |
|---|-----|-----|--------|
| Типизация | статическая | динамическая | динамическая |
| Неиспользуемые импорты/переменные | ошибка компиляции | нет | нет |
| `null` | `nil` только для ссылочных типов | `null`/`undefined` | `None` |

## Типичные ошибки

- `:=` вне функции — синтаксическая ошибка.
- Сравнение `float64` через `==` для денег — лучше целые копейки или `decimal` (в intermediate).
- Путать `byte` и `rune` при работе со строками — см. [04-control-flow.md](04-control-flow.md).
