# 01. Ландшафт интервью и план подготовки

## Введение

Алгоритмическая секция — не «знать 500 задач наизусть», а **узнавать паттерн**, писать **рабочий код** за 25–35 минут и **объяснять** сложность. На Python это плюс (краткий синтаксис) и минус (собеседник ждёт аккуратности с типами и edge cases).

---

## Форматы

| Формат | Длительность | Что смотрят |
|--------|--------------|-------------|
| Live coding | 45–60 мин | 1–2 задачи + вопросы |
| Take-home | 2–4 ч | чистота, тесты, README |
| OA (online assessment) | лимит времени | много easy/medium |
| Pair programming | 60 мин | диалог, рефакторинг |

---

## Уровни задач

| Уровень | Ожидание | Доля на интервью |
|---------|----------|------------------|
| Easy | паттерн за 5 мин, код 10 мин | разминка / OA |
| Medium | паттерн 10–15 мин, код 15–20 мин | **основа** |
| Hard | редко для middle; часть senior | 0–1 на цикл |

Цель курса: **уверенный medium** на Python.

## Python на интервью

| Делайте | Избегайте |
|---------|-----------|
| `def solve(nums: list[int]) -> int:` | классы без нужды |
| говорить сложность вслух | магические однобуквенные везде |

| уточнить вход (пустой? дубликаты?) | молча угадывать |

## Подзадачи

**Время:** ~50 мин.

### 1.1 Цель (10 мин)

Запишите: компания/тип интервью, дата (или «через 2 мес»), целевой уровень (middle/senior).

### 1.2 Диагностика (15 мин)

Решите 2 easy без подсказок (например Two Sum, Valid Parentheses). Засеките время. Запишите, где застряли.

### 1.3 Расписание (15 мин)

Перенесите 8-недельный шаблон в календарь: конкретные дни и главы курса.

### 1.4 Тетрадь ошибок (10 мин)

Создайте файл `mistakes.md`: шаблон — дата | задача | ошибка | паттерн-напоминание.

### 1.5 Setup (10 мин)

Поднимите venv в `examples/`, запустите `pytest` (должны быть FAIL на NotImplemented — это ок).
