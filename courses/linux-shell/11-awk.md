# 11. awk — отчёты и разбор полей

## Введение: «посчитай ошибки в логе за час»

`grep error log | wc -l` не покажет **топ IP** и не сгруппирует по полю. **awk** — стандарт для табличного текста: `/etc/passwd`, `df -h`, `ss`, journalctl, access.log.

Однострочник awk часто короче и быстрее bash-цикла `while read`.

## Что вы узнаете

- Модель: **запись** (строка), **поля** `$1`, `$2`…
- **`-F`** разделитель, **`NR`**, **`NF`**, **`$0`**, **`$NF`**.
- Условия и блоки **BEGIN** / **END**.
- **`printf`** для колонок.
- Когда **jq** лучше awk.

---

## Базовый вывод полей

```bash
awk '{print $1, $3}' /etc/passwd | head
awk -F: '{print "user=" $1, "uid=" $3, "home=" $6}' /etc/passwd | head
```

| Переменная | Значение |
|------------|----------|
| `$0` | вся строка |
| `$1`, `$2`… | поля |
| `$NF` | последнее поле |
| `NR` | номер строки |
| `NF` | число полей |

---

## Разделитель -F

```bash
df -h | awk 'NR>1 {print $1, $5, $6}'
```

**`NR>1`** — пропустить заголовок `df`.

---

## Условия

```bash
awk -F: '$3 >= 1000 {print $1}' /etc/passwd
awk '/error|fail/i {count++} END {print count+0}' log.txt
```

---

## BEGIN и END

```bash
awk '{sum+=$1} END {print "total", sum}' numbers.txt
awk 'BEGIN {print "uid\tuser"} {print $3"\t"$1}' /etc/passwd | head
```

**END** выполняется после всех строк — итоги, агрегаты.

---

## printf — ровные колонки

```bash
awk -F: '{printf "%-15s %6s %s\n", $1, $3, $6}' /etc/passwd | head
```

---

## journal + awk (пример)

```bash
journalctl -u ssh --no-pager -n 2000 2>/dev/null | \
  awk '/Failed password/ {ip[$11]++} END {for (i in ip) print ip[i], i}' | sort -rn | head
```

**Важно:** номер поля IP зависит от формата лога — проверьте `awk '{print $11}'` на одной строке.

---

## ss / порты

```bash
ss -tlnp 2>/dev/null | awk 'NR>1 {print $4}' | sed 's/.*://' | sort -n | uniq -c | sort -rn | head
```

---

## Когда не awk

| Данные | Инструмент |
|--------|------------|
| JSON | `jq` |
| YAML | `yq`, Python |
| сложная логика | Python |
| CSV с кавычками | `mlr`, Python csv |

---

## Типичные ошибки

| Ошибка | Исправление |
|--------|-------------|
| забыли `-F:` для passwd | неверные поля |
| сравнение строк как чисел | приведение `$5+0` |
| огромный файл без buffer | awk OK; избегайте shell while |

---

## В продакшене

Отчёты cron: awk + mail. Для метрик — Prometheus, не awk в cron на год.

---

## Резюме

**awk** — поля, фильтры, **END** для сумм. **`-F`**, **`NR`**, **`$NF`**. Проверяйте номера полей на реальной строке лога.
