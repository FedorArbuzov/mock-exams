# 23. DP 2D and knapsack

## Intro

Two dimensions: two strings, grid path, 0/1 knapsack. `dp[i][j]` — the answer to a subproblem; often it can be compressed to 1D.

---

## Unique paths grid

```python
def unique_paths(m: int, n: int) -> int:
    row = [1] * n
    for _ in range(1, m):
        for j in range(1, n):
            row[j] += row[j - 1]
    return row[-1]
```

---

## 0/1 Knapsack

```python
def knapsack(weights: list[int], values: list[int], cap: int) -> int:
    dp = [0] * (cap + 1)
    for w, v in zip(weights, values):
        for c in range(cap, w - 1, -1):  # reverse!
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[cap]
```

Reverse loop — each item once.
