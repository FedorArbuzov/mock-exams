## Core 40 (recommended list)

**Arrays:** Two Sum, 3Sum, Container Water, Trapping Rain, Max Subarray  
**Window:** Longest Substring, Min Window  
**Hash:** Group Anagrams, Top K Frequent, Longest Consecutive  
**BS:** Search Rotated, Koko Bananas  
**Stack:** Valid Paren, Daily Temps  
**List:** Reverse, Merge K, Cycle  
**Tree:** Invert, Level Order, Validate BST, LCA, Diameter, Max Path Sum  
**Graph:** Islands, Clone, Course Schedule  
**Heap:** Kth Largest, Merge K Lists  
**Intervals:** Merge, Meeting Rooms II  
**DP:** Climb Stairs, Coin Change, House Robber, LIS, Unique Paths, LCS, Edit Distance  
**BT:** Subsets, Permutations, Combination Sum
