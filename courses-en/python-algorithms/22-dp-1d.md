# 22. Dynamic programming 1D

## Intro

DP — optimal substructure + **overlapping** subproblems. 1D: `dp[i]` — the answer on the prefix/position i.

---

## Template

```python
def climb_stairs(n: int) -> int:
    if n <= 2:
        return n
    a, b = 1, 2
    for _ in range(3, n + 1):
        a, b = b, a + b
    return b
```

Space optimization: keep only the needed past states.

---

## Coin change

```python
def coin_change(coins: list[int], amount: int) -> int:
    inf = amount + 1
    dp = [inf] * (amount + 1)
    dp[0] = 0
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a:
                dp[a] = min(dp[a], dp[a - c] + 1)
    return dp[amount] if dp[amount] != inf else -1
```
