# Author reference

Students type inventory and clone Kubespray in `~/kuber-cka`. These files are a picture of a working stand, not a checkout target.

| File | What |
|------|------|
| [lxc-setup.sh](lxc-setup.sh) | three privileged LXC nodes + SSH |
| [inventory/hosts.yaml](inventory/hosts.yaml) | Kubespray host groups |
| [inventory/k8s-cluster.yml](inventory/k8s-cluster.yml) | version / CRI / CNI pins |
