# 14. k3s in twenty minutes

Optional. **Do not** replace the kubeadm cluster with this unless you `vagrant destroy` first — port 6443 and RAM.

k3s is a single binary: apiserver+etcd (or sqlite), kubelet, container runtime. Common for edge and homelabs.

On a **throwaway** Ubuntu VM (or a fourth Vagrant box):

```bash
curl -sfL https://get.k3s.io | sh -
sudo k3s kubectl get nodes
```

Workers:

```bash
# token from /var/lib/rancher/k3s/server/node-token on the server
curl -sfL https://get.k3s.io | K3S_URL=https://<server>:6443 K3S_TOKEN=<token> sh -
```
