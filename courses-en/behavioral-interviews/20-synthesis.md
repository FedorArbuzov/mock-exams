# 20. Synthesis: Story Portfolio

## Final task

Assemble a **Story Portfolio** — a single document to review 24 hours before an interview. Time: **2–3 hours**.

---

## Deliverable: Story Portfolio

### 1. Meta

| Field | Value |
|------|----------|
| Target role | backend / DevOps / SRE |
| Level | middle / senior |
| Company (type) | |
| Interview date | |

### 2. Pitches

- **30 sec** tell me about yourself  
- **2 min** version  
- **Why us** (5 sentences)  
- **Why leaving** (3 sentences)

### 3. Story index

| ID | Title | Competencies | 60-sec hook |
|----|-------|-------------|-------------|
| … | … | … | one line |

At least **8** full STAR stories in the appendix.

### 4. Question map

| Typical question | ID | Backup ID |
|-----------------|-----|-----------|
| Conflict | | |
| Failure | | |
| … | | |

### 5. Reverse questions

Top **10** marked "already asked in round 1".

### 6. Consistency sheet

Metrics and dates across stories (don't contradict yourself).

### 7. English (if needed)

2 stories — bullet STAR in English.

### 8. Mock scores

From [19](19-mock-scenarios.md): scenario | average score | top fix.

### 9. Red lines

NDA / do-not-discuss topics.

### 10. Day-before checklist

- [ ] Read the portfolio once  
- [ ] 2 stories out loud  
- [ ] 5 reverse questions  
- [ ] Sleep / logistics
