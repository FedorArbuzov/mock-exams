# М7 У1 · Диаграммы

## Diagram 01: Воронка рисков коммуникации

- Этапы: "Бриф" -> "Смета" -> "Старт" -> "Изменения" -> "Сдача".
- На каждом этапе отметить типовой риск и нужный документ.
- Цвета: риск (красный), контроль (зеленый), нейтральный процесс (синий).

## Diagram 02: Протокол согласования изменений

- Блок-схема из 7 шагов:
  1) Запрос изменения  
  2) Оценка влияния  
  3) Варианты решения  
  4) Подтверждение клиента  
  5) Акт изменения  
  6) Обновление сметы/графика  
  7) Выполнение

## Diagram 03: Матрица конфликтов

- Оси:
  - X: срочность (низкая -> высокая)
  - Y: влияние на безопасность/стоимость (низкое -> высокое)
- Для каждого квадранта указать рекомендуемый формат ответа.
