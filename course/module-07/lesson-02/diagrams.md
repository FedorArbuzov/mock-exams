# М7 У2 · Диаграммы

## Diagram 01: FARA в эскалации

- 4 блока: Facts -> Assumptions check -> Resolution options -> Agreement.
- Для каждого блока добавить вход/выход и срок.

## Diagram 02: Ветка приемки

- Старт: "Этап готов".
- Разветвление:
  - "Без замечаний" -> акт подписан -> оплата.
  - "Есть замечания" -> протокол -> срок исправления -> повторная приемка.

## Diagram 03: Матрица претензий

- Ось X: доказуемость (низкая/высокая).
- Ось Y: влияние (низкое/высокое).
- Для каждого квадранта дать стратегию ответа.

## Diagram 04: Жизненный цикл гарантийного обращения

- Обращение -> регистрация -> диагностика -> классификация -> решение -> выполнение -> закрытие.
- Отдельно показать SLA на каждом шаге.
