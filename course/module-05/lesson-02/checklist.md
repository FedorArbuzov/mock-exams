# М5 У2 · Чек-лист навыков

Студент после урока должен уметь:

- [ ] Строить карту потока задач end-to-end.
- [ ] Находить минимум 8 потерь в рабочем процессе.
- [ ] Применять 5S к физическому и цифровому контуру.
- [ ] Настраивать стандарты naming и хранения файлов.
- [ ] Формулировать DoR и DoD для типовых задач.
- [ ] Выстраивать SLA взаимодействия со смежниками.
- [ ] Готовить шаблон качественного handoff.
- [ ] Классифицировать входящие прерывания по критичности.
- [ ] Защищать deep work через time-blocking.
- [ ] Использовать ежедневный shutdown ritual.
- [ ] Отслеживать lead time, block time и reopen rate.
- [ ] Проводить двухнедельный антихаос-цикл улучшений.
