# М5 У2 · Словарь терминов

- **Рабочий поток** — цепочка этапов прохождения задачи от входа до завершения.
- **Lead time** — полное время выполнения задачи.
- **Cycle time** — время активной работы без ожиданий.
- **Handoff** — передача задачи/результата между участниками процесса.
- **Definition of Ready (DoR)** — критерии готовности задачи к старту.
- **Definition of Done (DoD)** — критерии завершенности задачи.
- **SLA взаимодействия** — договоренный срок реакции и решения.
- **Эскалация** — перевод проблемы на следующий уровень ответственности.
- **5S** — метод структурирования рабочего пространства и процессов.
- **Deep work** — непрерывная фокусная работа без отвлечений.
- **Контекстное переключение** — переход между задачами с потерей концентрации.
- **Backlog** — упорядоченный список задач по приоритетам.
- **Блокер** — фактор, останавливающий движение задачи.
- **Shutdown ritual** — короткий ритуал завершения рабочего дня.
- **Root cause analysis** — анализ первопричины повторяющейся проблемы.
