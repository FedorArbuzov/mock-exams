# М5 У2 · Диаграммы для генерации SVG

## Diagram 01: Поток задачи end-to-end

- Формат: горизонтальная блок-схема.
- Этапы: "Вход" -> "DoR" -> "Работа" -> "Проверка" -> "Handoff" -> "Done".
- На каждом этапе показать среднее время и точки ожидания.

## Diagram 02: 5S рабочего пространства

- Формат: пятисекторная схема.
- Сектора: Sort, Set in order, Shine, Standardize, Sustain.
- Для каждого сектора указать 2-3 конкретные практики.

## Diagram 03: SLA-матрица смежников

- Формат: таблица ролей.
- Колонки: роль, канал, SLA ответа, SLA решения, эскалация.
- Строки: аналитик, дизайнер, QA, менеджер, DevOps.

## Diagram 04: Карта прерываний

- Формат: decision tree.
- Ветки: критические, важные, шумовые.
- Для каждой ветки указать время реакции и маршрут обработки.

## Diagram 05: Антихаос-петля улучшений

- Формат: цикл PDCA.
- Шаги: Plan -> Do -> Check -> Act.
- На шаге Check вывести метрики: lead time, block time, reopen rate.
