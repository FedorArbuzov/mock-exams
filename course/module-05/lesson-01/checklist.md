# М5 У1 · Чек-лист навыков

Студент после урока должен уметь:

- [ ] Описывать быт как управляемый поток задач.
- [ ] Находить ключевые бытовые потери времени.
- [ ] Назначать владельцев бытовых процессов.
- [ ] Формулировать триггеры и SLA для рутины.
- [ ] Настраивать weekly review на 20-30 минут.
- [ ] Строить базовый канбан бытовых задач.
- [ ] Подготавливать шаблоны коммуникации со смежниками.
- [ ] Использовать чек-лист приемки услуг.
- [ ] Применять батчинг для снижения переключений.
- [ ] Собирать 5 базовых KPI бытовой системы.
- [ ] Запускать антихаос-цикл на 14-30 дней.
- [ ] Проводить ревизию узких мест ежемесячно.
