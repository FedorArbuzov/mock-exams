# М5 У1 · Диаграммы для генерации SVG

## Diagram 01: Поток бытового процесса

- Формат: value stream map.
- Этапы: "Планирование" -> "Закупка" -> "Исполнение" -> "Контроль".
- Для каждого этапа добавить время и типовые задержки.
- Потери выделить красным.

## Diagram 02: Роли и смежники

- Формат: swimlane-диаграмма.
- Линии: семья, сервисы, подрядчики.
- Показать точки передачи ответственности.

## Diagram 03: Недельный ритм антихаоса

- Формат: календарная сетка.
- Блоки: daily reset, weekly review, сервисные окна.
- Добавить контрольные точки проверки системы.

## Diagram 04: Цепочка бытового сбоя

- Формат: причинно-следственная схема.
- Шаги: "Нет триггера" -> "Пропуск задачи" -> "Аврал" -> "Срыв рабочего дня".
- В конце указать профилактическое действие.

## Diagram 05: KPI-панель быта

- Формат: dashboard sketch.
- Метрики: рутина/неделя, внеплановые поездки, просрочки, конфликты расписаний, выполнено по плану.
- Добавить зеленую/желтую/красную зоны для каждой метрики.
