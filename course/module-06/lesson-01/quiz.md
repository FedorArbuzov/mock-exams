# Квиз к уроку 1: Последовательность работ

1. С какого действия начинается этап «Последовательность работ»?
- A) С проверки проекта и привязок
- B) С закупки чистовых изделий
- C) С финишной отделки
- D) С демонтажа щита
- **Правильный ответ:** A

2. Что обязательно контролируется после выполнения операций этапа?
- A) Промежуточное качество и соответствие проекту
- B) Только скорость работы
- C) Только расход материала
- D) Только внешний вид упаковки
- **Правильный ответ:** A

3. Какой результат считается корректным?
- A) Этап выполнен по проекту и готов к следующему шагу
- B) Этап завершен без замеров
- C) Этап выполнен частично
- D) Этап перенесен без фиксации
- **Правильный ответ:** A

4. Что из перечисленного является типовой ошибкой?
- A) Пропуск проверки исходных привязок
- B) Ведение маркировки
- C) Проверка уровней
- D) Контроль качества
- **Правильный ответ:** A

5. Основной принцип урока «Последовательность работ»?
- A) Строгое следование технологической последовательности
- B) Импровизация без проекта
- C) Смешение электрики и общестроя
- D) Отмена контроля
- **Правильный ответ:** A
