# Диаграммы к уроку 13: Монтаж чистовых электроустановочных изделий

## Диаграмма 1. Поток работ
Входные данные -> Подготовка -> Выполнение этапа «Монтаж чистовых электроустановочных изделий» -> Контроль -> Передача на следующий этап.

## Диаграмма 2. Контроль качества
Проверка привязок -> Проверка геометрии/уровня -> Проверка соответствия проекту -> Фиксация результата.

## Диаграмма 3. Точки риска
Риск: неверная привязка -> Последствие: смещение монтажных точек -> Профилактика: двойная проверка перед работой.
Риск: пропуск контроля -> Последствие: переделки -> Профилактика: чек-лист после каждой операции.
