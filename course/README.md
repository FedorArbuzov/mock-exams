# Курс: Электромонтаж квартир (РФ)

Полный практико-ориентированный курс для подготовки электромонтажника квартирного сегмента.

## Как устроен курс

- Структура строго повторяет программу пользователя по модулям и урокам.
- Каждый урок проходит полный цикл: планирование, разработка, ревью, доработка, практика, тест, домашнее задание, конспект, чек-лист.
- Основной формат контента: Markdown-файлы, готовые к публикации в LMS или в статическом сайте.

## Навигация

- Общий индекс: `course/index.md`
- Карта программы и зависимости: `course/curriculum-map.md`
- Материалы уроков: `course/module-XX/lesson-YY/`
- Нормативные справки и источники: `course/references/`, `course/normative/`
