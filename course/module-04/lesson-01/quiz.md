# М4 У1 · Тест по СИЗ

Формат: один правильный ответ. Минимум для уверенного прохождения: 18/22.

1. Главная цель применения СИЗ в электромонтаже:  
A) Ускорить сдачу объекта  
B) Снизить риск травм и тяжесть последствий  
C) Сократить расход инструмента  
D) Упростить смету  
**Ответ:** B

2. Что нужно сделать перед началом смены?  
A) Только зарядить шуруповерт  
B) Проверить СИЗ на целостность и сухость  
C) Надеть только перчатки  
D) Открыть окна  
**Ответ:** B

3. Для штробления обязательно:  
A) Только каска  
B) Очки, респиратор, защита слуха  
C) Только беруши  
D) Только респиратор  
**Ответ:** B

4. Когда диэлектрические перчатки надо вывести из работы?  
A) Когда стали грязными  
B) При любых трещинах, проколах, потере эластичности  
C) Через год после покупки  
D) После дождя  
**Ответ:** B

5. Ошибка применения СИЗ:  
A) Проверка линз очков  
B) Снятие очков во время реза "на минуту"  
C) Хранение в отдельном контейнере  
D) Замена поврежденного фильтра  
**Ответ:** B

6. Что критично для каски?  
A) Цвет  
B) Целостность корпуса и подвески  
C) Наклейки  
D) Вес менее 100 г  
**Ответ:** B

7. Почему мокрые перчатки опасны?  
A) Пачкают кабель  
B) Ухудшают защитные свойства и хват  
C) Тяжелее сушить  
D) Шумят  
**Ответ:** B

8. Очки с глубокими царапинами:  
A) Можно использовать в темном помещении  
B) Можно использовать только при сверлении  
C) Нужно заменить  
D) Можно надеть поверх обычных  
**Ответ:** C

9. Защита слуха нужна:  
A) Только зимой  
B) При длительной работе шумным инструментом  
C) Только на улице  
D) Только при приемке  
**Ответ:** B

10. Что делать с СИЗ после падения каски с высоты?  
A) Продолжать работу  
B) Осмотреть и при малейших повреждениях заменить  
C) Протереть и убрать  
D) Отдать стажеру  
**Ответ:** B

11. Респиратор без рабочего фильтра:  
A) Допустим на короткое время  
B) Недопустим  
C) Допустим при открытых окнах  
D) Допустим только в коридоре  
**Ответ:** B

12. Главное правило хранения диэлектрических перчаток:  
A) Сложить в плотный узел  
B) Хранить без перегибов и нагрева  
C) Подвесить на гвоздь  
D) Держать рядом с растворителем  
**Ответ:** B

13. При работе в пыльной штробе нельзя:  
A) Использовать респиратор  
B) Использовать очки закрытого типа  
C) Работать без защиты дыхания  
D) Проверять посадку маски  
**Ответ:** C

14. Что делает профессионал, заметив дефект СИЗ?  
A) Заканчивает участок и потом меняет  
B) Игнорирует, если "терпимо"  
C) Останавливает работу и заменяет СИЗ  
D) Просит коллегу работать вместо него  
**Ответ:** C

15. Подмена диэлектрических перчаток бытовыми:  
A) Допустима при низком напряжении  
B) Недопустима  
C) Допустима при сухом воздухе  
D) Допустима в перерыве  
**Ответ:** B

16. Выбор СИЗ зависит прежде всего от:  
A) Бренда  
B) Цены  
C) Риска конкретной операции  
D) Советa продавца  
**Ответ:** C

17. Что повышает риск инцидента сильнее всего?  
A) Работа по чек-листу  
B) Спешка и отказ от части СИЗ  
C) Парная проверка  
D) Фиксация дефектов  
**Ответ:** B

18. Для переноса тяжелого инструмента важнее всего:  
A) Защита глаз  
B) Усиленный носок обуви и перчатки  
C) Защита слуха  
D) Щиток лица  
**Ответ:** B

19. Какая практика верная?  
A) Один комплект СИЗ на бригаду  
B) Индивидуальные СИЗ и персональная ответственность  
C) Очки только у мастера  
D) Перчатки по желанию  
**Ответ:** B

20. Что снижает число травм на объекте?  
A) Только опыт  
B) Регулярный предсменный осмотр СИЗ  
C) Уменьшение перерывов  
D) Работа в одиночку  
**Ответ:** B

21. Признак изношенной спецобуви:  
A) Новая стелька  
B) Отслоение подошвы и потеря сцепления  
C) Грязный шнурок  
D) Яркий цвет  
**Ответ:** B

22. Ключевой принцип урока:  
A) СИЗ нужны только на сложных объектах  
B) СИЗ — формальность для проверки  
C) СИЗ эффективны только при правильном выборе, состоянии и применении  
D) СИЗ заменяют правила электробезопасности  
**Ответ:** C
