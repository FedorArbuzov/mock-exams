# М4 У1 · Диаграммы (СИЗ)

## Diagram 01: Матрица выбора СИЗ
- Формат: таблица-матрица.
- Ось X: операции (`штробление`, `сверление`, `монтаж щита`, `работа на высоте`, `влажная зона`).
- Ось Y: СИЗ (`каска`, `очки`, `перчатки`, `обувь`, `слух`, `дыхание`).
- Ячейки: `обязательно` / `рекомендуется`.

## Diagram 02: Предсменный осмотр
- Формат: линейный процесс из 6 блоков.
- Блоки: `осмотр` -> `проверка посадки` -> `проверка сухости/чистоты` -> `фиксация дефектов` -> `замена` -> `допуск к работам`.

## Diagram 03: Цепочка инцидента без СИЗ
- Формат: причинно-следственная схема.
- Шаги: `отказ от СИЗ` -> `контакт с фактором риска` -> `травма/ожог/поражение` -> `остановка работ` -> `ущерб`.

## Diagram 04: Жизненный цикл СИЗ
- Формат: цикл.
- Этапы: `выдача` -> `использование` -> `очистка` -> `хранение` -> `периодический контроль` -> `списание`.

## Diagram 05: Типовые дефекты СИЗ
- Формат: 5 карточек с иконками.
- Карточки: `трещина каски`, `царапины очков`, `прокол перчатки`, `износ подошвы`, `забитый фильтр`.
