# М4 У1 · Чек-лист навыков

Студент после урока должен уметь:

- [ ] Объяснить, зачем СИЗ в электромонтаже и какие риски они закрывают.
- [ ] Подобрать СИЗ под 5 типовых операций на объекте.
- [ ] Выполнить предсменный осмотр по чек-листу.
- [ ] Выявить минимум 8 дефектов СИЗ.
- [ ] Принять решение о допуске/замене СИЗ без компромиссов.
- [ ] Объяснить правила хранения диэлектрических перчаток.
- [ ] Организовать базовый учет выдачи и списания СИЗ.
- [ ] Назвать типовые ошибки применения СИЗ и меры профилактики.
- [ ] Описать безопасную практику работы бригады в пыли/шуме/влаге.
- [ ] Подготовить короткий инструктаж по СИЗ для нового сотрудника.
