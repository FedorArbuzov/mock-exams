# М4 У3 · Глоссарий (электромонтажный инструмент)

- **Индикатор напряжения** — прибор для проверки наличия/отсутствия напряжения.
- **Мультиметр** — универсальный измерительный прибор электрических параметров.
- **Щупы** — контактные провода мультиметра для измерений.
- **Категория измерений** — класс безопасного применения прибора в сети.
- **Стриппер** — инструмент для снятия изоляции без повреждения жилы.
- **Кабелерез** — инструмент для ровной резки кабеля/провода.
- **Кримпер (пресс-клещи)** — инструмент для обжима наконечников.
- **Матрица обжима** — профильная часть кримпера под конкретный размер наконечника.
- **Наконечник** — элемент для надежного подключения жилы к клемме.
- **Гильза** — трубчатый элемент для опрессовки/соединения жил.
- **Моножила** — однопроволочный проводник.
- **Многопроволочная жила** — проводник из множества тонких проволок.
- **Разделка кабеля** — подготовка кабеля к монтажу.
- **Длина зачистки** — длина снятой изоляции перед подключением.
- **Клемма** — контактный узел подключения проводника.
- **Момент затяжки** — контролируемое усилие затяжки винтового контакта.
- **Недотяжка** — недостаточное усилие, вызывающее плохой контакт.
- **Перетяжка** — чрезмерное усилие с риском деформации контакта.
- **Переходное сопротивление** — сопротивление в месте соединения.
- **Локальный нагрев** — перегрев ограниченного участка контакта.
- **Маркировка проводников** — идентификация цепей и линий.
- **Протяжка контактов** — повторный контроль затяжки соединений.
