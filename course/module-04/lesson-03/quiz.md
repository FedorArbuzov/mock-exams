# М4 У3 · Тест по электромонтажному инструменту

Формат: один правильный ответ. Проходной уровень: 18/22.

1. Что нужно подтвердить перед работой в щите?  
A) Наличие фонаря  
B) Отсутствие напряжения проверенным прибором  
C) Цвет маркировки кабеля  
D) Марку автомата  
**Ответ:** B

2. Главная ошибка при зачистке жилы ножом:  
A) Медленная работа  
B) Надрез проводника и ослабление сечения  
C) Неровная изоляция  
D) Потеря маркера  
**Ответ:** B

3. Для надежного обжима наконечника применяют:  
A) Пассатижи  
B) Пресс-клещи с подходящей матрицей  
C) Молоток  
D) Разводной ключ  
**Ответ:** B

4. Чем опасен наконечник не по сечению?  
A) Удорожает работу  
B) Плохой контакт и нагрев  
C) Сложнее подписывать  
D) Портит внешний вид  
**Ответ:** B

5. Признак износа кримпера:  
A) Новая рукоятка  
B) Неполный или неравномерный обжим  
C) Тихая работа  
D) Слабый цвет металла  
**Ответ:** B

6. Почему важен контроль момента затяжки?  
A) Для скорости  
B) Чтобы избежать недо- и перетяжки клемм  
C) Для красоты щита  
D) Для экономии наконечников  
**Ответ:** B

7. Что может дать ложные показания мультиметра?  
A) Чистый корпус  
B) Слабая батарея или поврежденные щупы  
C) Короткие провода  
D) Новые перчатки  
**Ответ:** B

8. Ошибка маркировки в щите приводит к:  
A) Снижению шума  
B) Ошибкам при обслуживании и аварийным переключениям  
C) Экономии времени  
D) Уменьшению тока  
**Ответ:** B

9. Что делать после сборки критичных соединений?  
A) Сразу закрыть щит  
B) Выполнить повторный контроль соединений  
C) Стереть метки  
D) Сменить автомат  
**Ответ:** B

10. Какой инструмент нужен для снятия изоляции без повреждения жилы?  
A) Любой нож  
B) Стриппер с корректной настройкой  
C) Плоскогубцы  
D) Напильник  
**Ответ:** B

11. Неверная практика при измерениях:  
A) Проверять исправность прибора до замера  
B) Использовать прибор неподходящей категории  
C) Осматривать щупы  
D) Держать щупы за изоляцию  
**Ответ:** B

12. Что повышает переходное сопротивление контакта?  
A) Качественный обжим  
B) Поврежденная жила и слабая затяжка  
C) Маркировка кабеля  
D) Ровная укладка  
**Ответ:** B

13. При срыве шлица клеммы нужно:  
A) Затянуть сильнее  
B) Оставить как есть  
C) Заменить винт/клемму и восстановить соединение  
D) Закрыть крышку  
**Ответ:** C

14. Для многопроволочной жилы в клемме обычно применяют:  
A) Скрутку без наконечника  
B) Наконечник соответствующего сечения  
C) Изоленту  
D) Пайку как единственный вариант  
**Ответ:** B

15. Что важно в инструменте с изолированными рукоятками?  
A) Только бренд  
B) Целостность изоляции без трещин  
C) Яркий цвет  
D) Металлический блеск  
**Ответ:** B

16. Почему нельзя обжимать "чем придется"?  
A) Это медленнее  
B) Невозможно гарантировать контакт и мехпрочность  
C) Сложно хранить инструмент  
D) Сильнее шум  
**Ответ:** B

17. Какая ошибка часто вызывает перегрев клемм?  
A) Повторная проверка  
B) Затяжка "на глаз"  
C) Маркировка цепей  
D) Запись в журнал  
**Ответ:** B

18. Когда нужен повторный контроль затяжки?  
A) Никогда  
B) После операций, где возможна вибрация/перераскладка проводов  
C) Только перед отпуском  
D) Только на новых объектах  
**Ответ:** B

19. Что делать при обнаружении надрезанной жилы?  
A) Изолировать и оставить  
B) Переделать разделку и соединение  
C) Усилить затяжку  
D) Добавить второй провод  
**Ответ:** B

20. Основной критерий выбора измерительного прибора:  
A) Размер экрана  
B) Соответствие задаче и безопасной категории применения  
C) Цвет щупов  
D) Стоимость батареи  
**Ответ:** B

21. Зачем вести журнал контроля инструмента?  
A) Для формальности  
B) Для отслеживания отказов и профилактики аварий  
C) Для закупки одежды  
D) Для отчета по времени  
**Ответ:** B

22. Ключевой принцип урока:  
A) Качество контакта определяется случайно  
B) Надежность контактов обеспечивается правильным инструментом и контролируемым применением  
C) Главное — скорость расключения  
D) Проверка не обязательна  
**Ответ:** B
