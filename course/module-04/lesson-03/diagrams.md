# М4 У3 · Диаграммы (электромонтажный инструмент)

## Diagram 01: Алгоритм безопасного расключения
- Формат: flowchart.
- Блоки: `отключение` -> `проверка отсутствия напряжения` -> `подготовка проводника` -> `обжим/зажим` -> `контроль момента` -> `маркировка` -> `финальный контроль`.

## Diagram 02: Ошибка контакта и последствия
- Формат: причинно-следственная цепочка.
- Шаги: `неверный инструмент` -> `дефект контакта` -> `рост сопротивления` -> `нагрев` -> `авария`.

## Diagram 03: Выбор инструмента по типу жилы
- Формат: decision table.
- Колонки: `моножила`, `многопроволочная`, `гибкий шнур`.
- Строки: `зачистка`, `наконечник`, `обжим`, `контроль`.

## Diagram 04: Контроль точки качества в щите
- Формат: карта щита с callout-метками.
- Метки: `длина зачистки`, `посадка жилы`, `момент затяжки`, `маркировка`.

## Diagram 05: Карта отказов инструмента
- Формат: heatmap.
- Оси: `инструмент` x `тип поломки`.
- Цель: показать, где чаще появляются дефекты и что проверять в первую очередь.
