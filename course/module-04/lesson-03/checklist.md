# М4 У3 · Чек-лист навыков

Студент после урока должен уметь:

- [ ] Подтвердить отсутствие напряжения корректным алгоритмом.
- [ ] Выбрать инструмент под тип жилы и способ соединения.
- [ ] Выполнить зачистку без повреждения проводника.
- [ ] Подобрать наконечник по сечению и типу жилы.
- [ ] Выполнить правильный обжим штатным кримпером.
- [ ] Контролировать момент затяжки клемм.
- [ ] Выполнить повторный контроль ключевых соединений.
- [ ] Распознать признаки дефектного контакта до сдачи объекта.
- [ ] Вести маркировку и журнал проверки инструмента.
- [ ] Объяснить, как ошибки инструмента приводят к авариям.
