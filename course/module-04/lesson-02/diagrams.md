# М4 У2 · Диаграммы (общестроительный инструмент)

## Diagram 01: Подбор инструмента по операции
- Формат: decision tree.
- Узлы: `операция` -> `материал` -> `инструмент` -> `оснастка`.
- Выход: рекомендуемая связка и запреты.

## Diagram 02: Цикл безопасной работы
- Формат: круг из 6 шагов.
- Шаги: `осмотр` -> `разметка` -> `подготовка зоны` -> `выполнение` -> `контроль` -> `очистка`.

## Diagram 03: Типовые отказы перфоратора
- Формат: fishbone (причинно-следственная).
- Ветки: `оснастка`, `перегрев`, `пыль`, `оператор`, `электропитание`.

## Diagram 04: Матрица "ошибка -> последствие"
- Формат: таблица 2xN.
- Ошибки: тупой бур, снятый кожух, перекос диска, отсутствие пылеудаления.
- Последствия: травма, брак, простой, перерасход расходников.

## Diagram 05: Регламент мини-ТО
- Формат: чек-лист-поток.
- Блоки: `очистка` -> `осмотр кабеля` -> `осмотр патрона` -> `проверка люфта` -> `проверка кнопки` -> `журнал`.
