# М4 У2 · Домашнее задание

## Цель
Отработать выбор, проверку и обслуживание общестроительного инструмента для безопасного чернового электромонтажа.

## Задание
Подготовьте `homework-lesson-02.md`:
1. Опишите объект (тип стен, объем штробления, количество отверстий).
2. Составьте инструментальную карту на 3 этапа: разметка, сверление, штробление.
3. Для каждого этапа укажите:
   - основной инструмент;
   - оснастку;
   - обязательные СИЗ;
   - типовые риски;
   - меры профилактики.
4. Создайте регламент мини-ТО инструмента на смену (минимум 12 пунктов).
5. Разберите 8 типовых поломок и дайте алгоритм действий бригадира.
6. Сформируйте список 10 ошибок применения, которые нужно исключить на объекте.

## Формат сдачи
- Markdown-файл.
- Опционально: таблица учета оснастки (`csv`).

## Критерии оценки
- Точность подбора инструмента/оснастки — 30%.
- Практичность мер безопасности — 30%.
- Качество регламента обслуживания — 25%.
- Полнота разбора ошибок/поломок — 15%.
