# М4 У2 · Тест по общестроительному инструменту

Формат: один правильный ответ. Проходной уровень: 18/22.

1. Что важно при выборе перфоратора?  
A) Цвет корпуса  
B) Энергия удара и соответствие задаче  
C) Длина шнура  
D) Наличие наклеек  
**Ответ:** B

2. Почему нельзя снимать защитный кожух УШМ?  
A) Потеряется гарантия  
B) Растет риск тяжелой травмы при разрушении диска  
C) Инструмент хуже режет  
D) Увеличивается шум  
**Ответ:** B

3. Для штробления в квартире правильно использовать:  
A) Только молоток  
B) Штроборез с пылеудалением  
C) Ножовку  
D) Любой диск на УШМ  
**Ответ:** B

4. Признак износа бура:  
A) Яркая маркировка  
B) Выкрашивание рабочей кромки  
C) Новый хвостовик  
D) Наличие чехла  
**Ответ:** B

5. Что нельзя делать при смене оснастки?  
A) Надевать перчатки  
B) Отключать инструмент от сети  
C) Менять оснастку при подключенном питании  
D) Проверять фиксацию  
**Ответ:** C

6. Зачем нужен строительный пылесос при штроблении?  
A) Для красоты  
B) Для снижения запыления и перегрева зоны реза  
C) Для уменьшения длины штробы  
D) Для экономии дисков  
**Ответ:** B

7. Основная причина закусывания диска:  
A) Низкая температура  
B) Перекос и неправильная подача  
C) Новый инструмент  
D) Мягкий материал  
**Ответ:** B

8. Что делать при запахе горелой изоляции от инструмента?  
A) Ускорить работу  
B) Остановить работу и отправить в диагностику  
C) Сменить оператора и продолжить  
D) Охладить водой  
**Ответ:** B

9. Ошибка при сверлении стены:  
A) Проверка трасс и коммуникаций  
B) Разметка по уровню  
C) Сверление без проверки скрытых коммуникаций  
D) Использование ограничителя глубины  
**Ответ:** C

10. Что снижает ресурс патрона?  
A) Чистка инструмента  
B) Работа с биением и грязным хвостовиком  
C) Регламентное обслуживание  
D) Аккуратное хранение  
**Ответ:** B

11. Для резки металла нельзя применять:  
A) Диск по металлу подходящего диаметра  
B) Поврежденный или просроченный диск  
C) Защитный щиток  
D) Фиксацию заготовки  
**Ответ:** B

12. Правильная практика хранения инструмента:  
A) Влажный подвал без кейсов  
B) Кейс и сухая зона хранения  
C) На полу у входа  
D) В коробке с расходниками россыпью  
**Ответ:** B

13. Что важнее скорости на черновом этапе?  
A) Работа без перерывов  
B) Безопасный режим и контроль качества  
C) Минимум разметки  
D) Максимум силы на инструменте  
**Ответ:** B

14. Причина быстрого перегрева инструмента:  
A) Паузы в работе  
B) Чрезмерное давление оператором  
C) Очистка от пыли  
D) Правильный расходник  
**Ответ:** B

15. Неверная практика:  
A) Проверка кабеля перед запуском  
B) Укладка кабеля питания в безопасную зону  
C) Прокладка кабеля питания через линию реза  
D) Проверка кнопки пуска  
**Ответ:** C

16. Когда расходник нужно списать немедленно?  
A) После одной смены  
B) При трещинах, сколах, деформации  
C) Когда закончился маркер  
D) Если нет этикетки  
**Ответ:** B

17. Что дает еженедельный техосмотр набора?  
A) Только отчетность  
B) Раннее выявление поломок и снижение простоев  
C) Увеличение шума  
D) Снижение точности разметки  
**Ответ:** B

18. Ошибка новичка при работе перфоратором:  
A) Подбор правильного бура  
B) Давление корпусом вместо рабочего режима  
C) Очистка хвостовика  
D) Проверка патрона  
**Ответ:** B

19. Почему нельзя работать тупой коронкой?  
A) Она тяжелее  
B) Растут перегрев, вибрация и риск брака  
C) Падает яркость света  
D) Не закрывается кейс  
**Ответ:** B

20. Что делать при люфте шпинделя УШМ?  
A) Игнорировать до конца объекта  
B) Передать в ремонт и не эксплуатировать  
C) Уменьшить обороты и продолжить  
D) Сменить диск  
**Ответ:** B

21. Безопасная последовательность перед запуском:  
A) Запуск -> осмотр -> разметка  
B) Осмотр -> фиксация заготовки -> запуск  
C) Разметка -> запуск -> поиск СИЗ  
D) Запуск без проверки  
**Ответ:** B

22. Ключевой принцип урока:  
A) Любой инструмент подходит для любой задачи  
B) Надежность достигается выбором правильного инструмента и дисциплиной обслуживания  
C) Главное — высокая мощность  
D) Обслуживание можно отложить до поломки  
**Ответ:** B
