# М4 У2 · Чек-лист навыков

Студент после урока должен уметь:

- [ ] Подбирать инструмент и оснастку под материал и операцию.
- [ ] Проверять инструмент перед запуском по безопасному алгоритму.
- [ ] Организовывать рабочую зону без риска повреждения кабеля питания.
- [ ] Работать с пылеудалением при штроблении и резке.
- [ ] Выявлять признаки перегрева, люфта и биения.
- [ ] Выполнять мини-ТО после смены.
- [ ] Списывать опасные расходники без попытки "доработать".
- [ ] Разбирать типовые поломки и назначать корректные действия.
- [ ] Предотвращать 10 распространенных ошибок применения.
- [ ] Вести журнал обслуживания инструмента бригады.
