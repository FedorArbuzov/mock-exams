# М4 У2 · Глоссарий (общестроительный инструмент)

- **Перфоратор** — инструмент для бурения и долбления твердых материалов.
- **Дрель** — инструмент для сверления без ударного долбления бетона.
- **Штроборез** — инструмент для резки параллельных каналов под коммуникации.
- **УШМ** — углошлифовальная машина для резки и шлифования с подходящей оснасткой.
- **Оснастка** — сменный рабочий элемент инструмента (диск, бур, коронка).
- **Бур** — режущий элемент перфоратора для сверления бетона/кирпича.
- **Коронка** — оснастка для высверливания круглых посадочных отверстий.
- **Патрон** — узел фиксации оснастки в инструменте.
- **Шпиндель** — вращающийся вал, передающий момент оснастке.
- **Люфт** — нежелательное свободное перемещение узла.
- **Биение** — отклонение вращения от оси, вызывающее вибрацию.
- **Пылеудаление** — удаление пыли из зоны обработки.
- **Режим работы** — набор параметров: обороты, удар, подача.
- **Перегрев** — превышение температурного режима инструмента.
- **Мини-ТО** — регулярное короткое техническое обслуживание.
- **Расходник** — элемент, который изнашивается и подлежит замене.
- **Срок службы оснастки** — период эффективной и безопасной работы расходника.
- **Закусывание диска** — блокировка диска из-за перекоса/зажима материала.
- **Скрытые коммуникации** — кабели, трубы и трассы внутри стен.
- **Строительный пылесос** — пылесос для минеральной/строительной пыли.
- **Простой** — потеря рабочего времени из-за неисправности.
- **Технологическая дисциплина** — строгое соблюдение порядка безопасной работы.
