# Этапы 1-3: Карта курса и зависимости

Полная карта модулей, планы уроков и gap-анализ подготовлены по утвержденной программе.

## Порядок модулей

`М1 -> М2 -> М3 -> М4 -> М5 -> М6 -> М7`

## Ключевые зависимости

- `М1.3 Электробезопасность` блокирует весь практический блок `М4.*` и `М6.*`.
- `М2.1 Кабели` блокирует `М2.2`, `М2.3`, `М6.8`, `М6.9`.
- `М2.4 Автоматы` блокирует `М2.5`, `М2.6`, `М3.1`, `М3.2`, `М3.4`.
- `М2.5 УЗО` блокирует `М3.2`, `М3.3`, `М3.4`, `М6.11`.
- `М3.4 Проект электрощита` блокирует `М6.1`, `М6.11`, `М6.12`.
- `М6.12 Подключение отходящих линий` блокирует `М6.13`, `М6.14`.

## Планы уроков

Для каждого урока курса подготовлен план из 10 подпунктов (минимум), включая:

- техническое содержание;
- практические действия на объекте;
- типовые ошибки;
- контрольные точки качества;
- межурочные связи.

## Gap-анализ

Чтобы закрыть практические пробелы и не менять основную структуру, рекомендованы бонусные уроки:

- Нормативка РФ для квартирного электромонтажа.
- Расчет нагрузок и выбор сечений на реальных кейсах.
- Диагностика неисправностей после монтажа.
- Исполнительная документация и акты.
- Смета, закупка, логистика объекта.

Детализация каждого пункта будет добавляться в `course/references/` по мере прохождения основных уроков.
