# М1 У3 · Диаграммы

Diagram: `Контур электробезопасности квартиры`  
Описание: уровни защиты от источника питания до конечного потребителя: изоляция, автомат, УЗО, PE, организационные меры.

Diagram: `Алгоритм безопасного начала работ`  
Описание: отключение -> проверка отсутствия напряжения -> контроль прибора -> допуск к операции -> повторная проверка.

Diagram: `Сценарий пробоя на корпус`  
Описание: путь аварийного тока через PE, фиксация утечки УЗО и автоматическое отключение.

Diagram: `Типовые причины поражения током`  
Описание: дерево причин: ошибки отключения, поврежденная изоляция, отсутствие PE, работы без СИЗ, ложная уверенность в обесточивании.

Diagram: `Точки контроля перед пуском`  
Описание: чек-поток проверок: визуальный осмотр -> затяжка клемм -> изоляция -> PE -> тест УЗО -> поэтапный пуск.

Diagram: `Связь ошибок монтажа и последствий`  
Описание: матрица "ошибка -> эффект -> риск": слабый контакт, неверная коммутация, отсутствие маркировки, пропуск тестов.

Diagram: `Памятка заказчику после сдачи`  
Описание: блоки "что можно", "что нельзя", "как действовать при аварии", "когда вызывать специалиста".
