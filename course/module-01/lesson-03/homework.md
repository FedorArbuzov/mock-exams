# М1 У3 · Домашняя работа

## Практическое задание

Разработайте регламент электробезопасности для выполнения чернового электромонтажа в квартире 58 м2 (ремонт с периодическим присутствием заказчика на объекте).

### Необходимо подготовить

1. Перечень рисков по этапам работ.
2. Матрицу "риск -> профилактика -> контроль".
3. Пошаговый алгоритм безопасного отключения и проверки отсутствия напряжения.
4. Список СИЗ и требований к инструменту.
5. План проверки PE, УЗО/дифавтоматов и контактных соединений.
6. Памятку для заказчика по безопасной эксплуатации после сдачи.

## Формат сдачи

- `homework-module01-lesson03.md` с четкой структурой:
  - вводные условия;
  - карта рисков;
  - регламент действий бригады;
  - контрольные процедуры;
  - выводы и рекомендации.

## Критерии оценки

1. **Реалистичность** — план применим на реальном объекте.
2. **Полнота** — учтены риски монтажа и эксплуатации.
3. **Техническая корректность** — меры соответствуют принципам электробезопасности.
4. **Проверяемость** — есть конкретные точки контроля и критерии "принято/не принято".
5. **Качество коммуникации** — материал понятен как бригаде, так и заказчику.

## Шкала оценки

- 90-100: регламент можно внедрять без существенных правок.
- 75-89: хорошая база, требуются точечные уточнения.
- 60-74: частичное покрытие рисков, нужна доработка.
- <60: работа не обеспечивает достаточный уровень безопасности.
