# М1 У3 · Чек-лист навыков

- [ ] Понимаю ключевые риски поражения током и пожара в квартирном монтаже.
- [ ] Соблюдаю порядок "обесточил — проверил — зафиксировал" без исключений.
- [ ] Умею корректно проверять отсутствие напряжения измерительным прибором.
- [ ] Применяю СИЗ и инструмент по типу работ.
- [ ] Умею объяснить различия в функциях автомата, УЗО и дифавтомата.
- [ ] Контролирую корректность подключения `L`, `N`, `PE`.
- [ ] Проверяю непрерывность PE перед сдачей системы.
- [ ] Выполняю тестирование УЗО/дифавтоматов по регламенту.
- [ ] Отслеживаю риски в влажных помещениях отдельно от остальных зон.
- [ ] Контролирую качество контактных соединений и момент затяжки.
- [ ] Веду журнал измерений и замечаний по объекту.
- [ ] Провожу поэтапный пуск линий после монтажа.
- [ ] Формирую понятную памятку заказчику по безопасной эксплуатации.
- [ ] Могу выявить типовые ошибки новичков и предотвратить их.
- [ ] Готов работать по стандарту электробезопасности на реальном объекте.
