# М1 У2 · Домашняя работа

## Практическое задание

Разработайте черновую структуру системы электроснабжения для квартиры 80 м2:

- кухня-гостиная;
- две спальни;
- санузел;
- постирочная;
- лоджия;
- рабочее место с компьютером и ИБП.

### Что требуется сделать

1. Подготовить список потребителей по помещениям.
2. Разбить электросеть на группы с названиями и назначением.
3. Выделить отдельные линии для мощной техники.
4. Предложить набор защитных устройств по группам.
5. Определить резерв в щите для будущего расширения.
6. Описать логику маркировки линий.
7. Составить перечень финальных проверок перед сдачей.

## Формат сдачи

- `homework-module01-lesson02.md` с разделами:
  - таблица групп;
  - обоснование решений;
  - риски и меры профилактики;
  - чек-лист контроля.

## Критерии оценки

1. **Техническая корректность** — решения соответствуют логике безопасного монтажа.
2. **Полнота группировки** — учтены все зоны и значимые потребители.
3. **Обоснованность защит** — выбор связан с линиями и нагрузкой.
4. **Эксплуатационная удобность** — схема понятна для обслуживания.
5. **Качество документации** — материал читаемый, структурированный, без противоречий.

## Шкала оценки

- 90-100 баллов: профессионально проработанная схема, готовая к реализации.
- 75-89 баллов: хорошее решение, есть отдельные недочеты по деталям.
- 60-74 балла: базовый уровень, требуется доработка логики групп/защит.
- менее 60 баллов: существенные ошибки, нужно повторить тему и пересдать.
