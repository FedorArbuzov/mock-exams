# М1 У2 · Чек-лист навыков

Отметьте каждый пункт после уверенного выполнения.

- [ ] Понимаю полную архитектуру электроснабжения квартиры от ввода до конечной точки.
- [ ] Могу объяснить назначение каждого элемента квартирного щита.
- [ ] Умею корректно разделять линии на функциональные группы.
- [ ] Учитываю мощные потребители и выделяю для них отдельные линии.
- [ ] Отличаю функции проводников `L`, `N`, `PE` и соблюдаю правила их применения.
- [ ] Подбираю защитные аппараты по логике линии, а не по "ощущению".
- [ ] Понимаю влияние формулы `I^2R` на нагрев контактов и кабеля.
- [ ] Учитываю риск падения напряжения на длинных и нагруженных линиях.
- [ ] Веду системную маркировку линий на всех этапах монтажа.
- [ ] Закладываю резерв в щите под расширение системы.
- [ ] Провожу промежуточные и финальные проверки перед сдачей.
- [ ] Формирую исполнительную документацию понятную для дальнейшего сервиса.
- [ ] Умею аргументировать технические решения заказчику.
- [ ] Вижу типовые ошибки группировки и могу их предотвратить.
- [ ] Готов перейти к уроку по электробезопасности.
