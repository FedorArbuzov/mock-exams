# М1 У2 · Диаграммы

Diagram: `Архитектура электроснабжения квартиры`  
Описание: этажный щит -> ввод в квартиру -> вводной аппарат -> блок защит -> групповые автоматы -> отходящие линии -> конечные потребители.

Diagram: `Группирование нагрузок`  
Описание: древовидная схема групп: освещение, розетки комнат, кухня, санузел, выделенные линии мощных потребителей.

Diagram: `Разделение функций L/N/PE`  
Описание: схема бытового прибора, где рабочий ток идет по L-N, а аварийный путь при пробое корпуса уходит по PE.

Diagram: `Выбор защиты по линии`  
Описание: блок-схема принятия решения: тип нагрузки -> расчетный ток -> выбор кабеля -> выбор автомата -> решение по УЗО/дифавтомату.

Diagram: `Логика маркировки в щите`  
Описание: пример нумерации линий (QF1.1, QF1.2...), соответствие с планом помещений и легендой.

Diagram: `Риски неверной группировки`  
Описание: сравнение двух вариантов: перегруженная объединенная схема против разделенной схемы с локализацией аварии.

Diagram: `Проверка перед сдачей`  
Описание: последовательность контроля: визуальный осмотр -> протяжка контактов -> тест изоляции -> тест УЗО -> функциональная проверка групп.
