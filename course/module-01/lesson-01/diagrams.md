# М1 У1 · Диаграммы для генерации SVG

## Diagram 01: Путь энергии в квартире

- Формат: горизонтальная блок-схема.
- Блоки: "Ввод в квартиру" -> "Вводной аппарат" -> "Электрощит" -> "Группы" -> "Нагрузки".
- В группах показать три ветки: "Освещение", "Розетки", "Выделенные линии".
- Цвета: питание — синий, защита — оранжевый, конечные точки — зеленый.

## Diagram 02: Функции L/N/PE

- Формат: простая электрическая схема прибора с металлическим корпусом.
- Показать нормальный режим: ток идет по L-N через нагрузку.
- Показать аварийный режим: пробой на корпус и отвод тока по PE.
- Подписи: "Рабочий путь тока", "Путь тока повреждения", "Опасное касание без PE".

## Diagram 03: Нагрев плохого контакта

- Формат: split-view (два соединения рядом).
- Слева: "Хороший контакт", справа: "Ослабленный контакт".
- Для обеих частей одинаковая нагрузка, разные значения переходного сопротивления.
- Визуально показать рост температуры справа (градиент красного цвета).

## Diagram 04: Рабочий цикл монтажника

- Формат: круговой процесс из 8 сегментов.
- Сегменты: "Замер" -> "Проект/согласование" -> "Разметка" -> "Черновой монтаж" -> "Расключение" -> "Сборка щита" -> "Проверка" -> "Сдача".
- Внутри круга: "Безопасность + Контроль качества на каждом этапе".

## Diagram 05: Цепочка ошибки

- Формат: вертикальная причинно-следственная диаграмма.
- Шаги: "Плохое решение" -> "Скрытый дефект" -> "Нагрев/утечка" -> "Срабатывание/авария" -> "Ущерб".
- Внизу добавить блок: "Точка профилактики: правильное планирование и проверка".
