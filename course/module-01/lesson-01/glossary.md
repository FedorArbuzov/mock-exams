# М1 У1 · Словарь терминов

- **Электрическая цепь** — совокупность элементов, по которым протекает ток.
- **Напряжение (U)** — разность потенциалов между двумя точками, которая создает движение заряда.
- **Сила тока (I)** — количество заряда, проходящее через проводник за единицу времени.
- **Сопротивление (R)** — параметр участка цепи, ограничивающий ток.
- **Мощность (P)** — скорость потребления электрической энергии.
- **Фаза (L)** — токоведущий проводник с потенциалом относительно нуля.
- **Ноль (N)** — рабочий проводник обратного пути тока в нормальном режиме.
- **PE (Protective Earth)** — защитный проводник для электробезопасности.
- **Переходное сопротивление** — сопротивление в месте электрического контакта.
- **Перегрузка** — режим, когда ток в линии выше допустимого длительного.
- **Короткое замыкание (КЗ)** — аварийное соединение с малым сопротивлением и резким ростом тока.
- **Ток утечки** — нежелательный ток по стороннему пути.
- **Групповая линия** — отдельная ветка питания части потребителей.
- **Электрощит** — узел распределения питания и размещения защитных устройств.
- **Маркировка линии** — подпись/обозначение кабеля по назначению.
- **Скрытые работы** — этапы, которые после отделки нельзя визуально проверить без вскрытия.
- **Ремонтопригодность** — возможность быстро диагностировать и исправлять неисправности.
- **Селективность** — принцип локального отключения аварийного участка без обесточивания всей квартиры.
- **Допуск к работам** — организационные и технические условия безопасного начала работ.
- **Исполнительная документация** — комплект фактических данных о том, как смонтирована система.
