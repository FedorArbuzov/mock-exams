## Практическое задание

Соберите учебный кейс: "Квартира 72 м2, кухня с мощной техникой, санузел с влажной зоной, часть трасс в ограниченном пространстве".  
Нужно подготовить и обосновать решение по теме "ЭУИ", затем оформить результат как для передачи бригаде.

## Что нужно сделать

1. Описать исходные данные и ограничения объекта.
2. Предложить техническое решение по теме урока.
3. Составить пошаговый план монтажа/проверки (не меньше 12 шагов).
4. Отдельно описать 5 рисков и 5 мер профилактики.
5. Подготовить комплект: схема, список материалов, чек самоконтроля.

## Формат сдачи

- `homework-report.md` с обоснованием решений;
- 3-6 схем/эскизов;
- таблица проверки качества;
- короткое видео или фотофиксация стенда (если есть доступ к стенду).

## Критерии оценки

- Техническая корректность и безопасность решения — 40%.
- Логика монтажа и проверок — 25%.
- Реалистичность для объекта в РФ-практике — 20%.
- Четкость документации и аргументации — 15%.

## Минимум для зачета

- Нет критичных нарушений по безопасности.
- Есть обоснование каждого ключевого решения.
- Есть понятный порядок действий и контроль качества.
