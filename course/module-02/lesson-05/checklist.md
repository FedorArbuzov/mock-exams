После урока студент должен уметь:

- [ ] Понимать задачу урока и ограничения объекта.
- [ ] Собирать исходные данные до начала работ.
- [ ] Делать технический выбор по теме с понятным обоснованием.
- [ ] Проверять решение по безопасности и ресурсу.
- [ ] Читать и корректировать схему под реальный объект.
- [ ] Маркировать линии и фиксировать изменения.
- [ ] Выполнять промежуточный контроль качества.
- [ ] Находить типовые ошибки до сдачи работ.
- [ ] Объяснять заказчику последствия неверного решения.
- [ ] Оформлять чек самоконтроля и протокол проверок.
- [ ] Учитывать влажность, температуру и механические риски.
- [ ] Планировать этапы без конфликта со смежниками.
- [ ] Готовить комплект фото скрытых работ.
- [ ] Работать по шагам без пропуска критичных проверок.
- [ ] Проверять совместимость материалов и устройств.
- [ ] Оценивать запас по режиму и надежности.
- [ ] Действовать безопасно на всех этапах монтажа.
- [ ] Проводить базовую диагностику узла.
- [ ] Передавать результат в понятном виде бригаде.
- [ ] Применять тему 'УЗО' в типовой квартире РФ.
