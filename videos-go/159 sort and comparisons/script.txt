How do I sort structs?

sort.Slice(slice, func(i,j int) bool { return slice[i].Score > slice[j].Score }). Go 1.21+ adds slices.SortFunc with cmp.Compare for cleaner comparisons.

Sorting requires explicit less function — no magic overloads.

Stable sort when equal elements must keep order: sort.SliceStable.
