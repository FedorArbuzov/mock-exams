My service is slow — where?

Use pprof. Import net/http/pprof on debug builds or go test -cpuprofile=cpu.out -bench=. Then go tool pprof cpu.out.

CPU profile shows hot functions. Heap profile shows allocations. Goroutine profile shows leaks.

Optimize what profiles prove — not what you guess.
