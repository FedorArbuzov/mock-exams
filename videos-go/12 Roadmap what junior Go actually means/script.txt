What skills get you hired?

Junior Go is not memorizing syntax. It is writing a small HTTP service, handling errors explicitly, using modules cleanly, testing with the testing package, and understanding goroutines without leaking them.

You should read structs, slices, maps, interfaces, and context. You should debug a failing test and explain why a nil interface check lied to you.

You do not need to know every stdlib package on day one. You do need to ship a repo that builds, tests, and formats cleanly.

Hiring bar checklist: modules, errors, interfaces, basic concurrency, one API or CLI project in Git.
