How do I unit test a DB call?

Depend on a small interface your code actually uses — maybe GetUser and SaveOrder — not *sql.DB directly. In tests, pass a fake that returns canned data.

Hand-written fakes are idiomatic Go. Giant mocking frameworks are optional.

The interface belongs at the consumer: func NewService(store UserStore) — Store defined as interface near Service.

Test seam: interface with two methods, fake struct in _test.go.
