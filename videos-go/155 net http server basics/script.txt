Can Go be my API server?

Yes. net/http is production-proven. Register handlers on a mux, listen with http.Server, set timeouts on the server struct — ReadHeaderTimeout, IdleTimeout.

Handler signature: func(w http.ResponseWriter, r *http.Request). Implement http.Handler or use HandlerFunc.
