How do I add auth logging once?

Middleware wraps http.Handler. func logging(next http.Handler) http.Handler { return HandlerFunc(func(w,r) { log; next.ServeHTTP(w,r) }) }.

Chain middleware: auth(logging(mux)). Each layer handles one concern.

Use response wrappers to capture status codes if your logger needs them.
