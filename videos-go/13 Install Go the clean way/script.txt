Which installer should I trust?

Download Go from go.dev — the official toolchain. On Windows use the MSI installer or the official archive. On macOS, the pkg from go.dev beats random Homebrew forks for beginners.

After install, open a new terminal and run go version. You want a recent stable release, not a random nightly.

Avoid mixing multiple Go installs unless you know what GOROOT means. One clean install saves hours of PATH confusion.

First-hour check: go version works, go env GOROOT points at that install, and your editor sees the same binary.
