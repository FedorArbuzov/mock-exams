Can't find the Pod - maybe the wrong namespace?

kubectl get pods dash A, or dash dash all-namespaces. It lists Pods across every namespace in one table, with a NAMESPACE column so you can see where each Pod actually lives.

This is the classic morning mistake fix. Your context points at default, the app runs in staging or payments, and get pods looks empty. Dash A ends the guessing. The same flag works on many resources - get deploy dash A, get svc dash A.

What beginners get wrong: running dash A on huge clusters without a filter and drowning in noise. Or forgetting that cluster-scoped resources like nodes ignore namespaces anyway. Also using dash A once, then forgetting to set the right namespace for the next commands.

Practical tip: after you spot the namespace, switch with kubectl config set-context dash dash current dash dash namespace equals that-name, or pass dash n on every command. Filter with grep or label selectors when the list is long.

Rule to remember: empty get often means wrong namespace - try dash A first.
