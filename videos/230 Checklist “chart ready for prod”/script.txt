When is a chart production-ready?

In simple terms, you need values validation, resources, probes, a rollback plan, and docs.

Concretely, treat that as a testable rule: You need values validation, resources, probes, a rollback plan, and docs. When reality disagrees, trust cluster signals over the story in your head.

Delivery quality is a bored repeatable path: pinned image, Git as source of truth, sync, smoke, rollback.

If humans must remember secret dashboard clicks, drift is already invited.

Beginner trap: kubectl edit in prod with no path back to Git.

If someone asks tomorrow what this changes, answer with the rule: you need values validation, resources, probes, a rollback plan, and docs.
