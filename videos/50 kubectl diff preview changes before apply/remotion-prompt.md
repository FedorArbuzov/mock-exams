Scene 2: kubectl diff. It compares your local manifest to the live object and prints a unified diff of what apply would change. You get a preview without mutating the cluster.
Scene 3: Use it as a safety gate. Before a production apply, run kubectl diff dash f manifest.yaml and read every red and green line. Unexpected deletions, image swaps, or replica jumps stand out immediately.
Scene 4: What beginners get wrong: applying blind because the YAML looks familiar. Or ignoring that diff needs RBAC - if it fails, fix permissions instead of skipping. Tip: review namespace and name carefully.
