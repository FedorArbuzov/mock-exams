Chart vs release — what's the difference?

In simple terms, a chart is an app template; a release is a concrete installed instance in the cluster.

Concretely, treat that as a testable rule: A chart is an app template; a release is a concrete installed instance in the cluster. When reality disagrees, trust cluster signals over the story in your head.

Delivery quality is a bored repeatable path: pinned image, Git as source of truth, sync, smoke, rollback.

If humans must remember secret dashboard clicks, drift is already invited.

Beginner trap: kubectl edit in prod with no path back to Git.
