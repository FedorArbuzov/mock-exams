Why are manual cluster edits dangerous?

In simple terms, source of truth should be Git so changes are visible and repeatable.

Concretely, treat that as a testable rule: Source of truth should be Git so changes are visible and repeatable. When reality disagrees, trust cluster signals over the story in your head.

Delivery quality is a bored repeatable path: pinned image, Git as source of truth, sync, smoke, rollback.

If humans must remember secret dashboard clicks, drift is already invited.

Beginner trap: kubectl edit in prod with no path back to Git.

If someone asks tomorrow what this changes, answer with the rule: source of truth should be Git so changes are visible and repeatable.
